# 实验五：跨数据集泛化

## 目标
验证意图提取器在不同领域数据集上的泛化能力。

## 设计
- 在 MultiWOZ（酒店/餐厅/交通）上训练/配置意图提取器
- 在 ABCD（客服中心）或 SGD（26 服务）上测试
- 评估跨领域时意图提取质量的下降幅度

## 变量
| 变量 | 取值 | 说明 |
|------|------|------|
| 训练数据集 | `multiwoz` | 源域 |
| 测试数据集 | `abcd`, `sgd` | 目标域 |
| 提取模式 | `template`, `llm` | 对比泛化能力 |

## 指标
| 指标 | 说明 |
|------|------|
| 意图提取准确率 | 目标域上的意图语义覆盖 |
| 评测分数分布 | 源域 vs 目标域的分数差异 |
| 领域偏移度 | 源域和目标域 embedding 距离 |

## 执行步骤

```bash
# 跨 MultiWOZ → ABCD
python src/run_experiment.py --exp exp5 --dataset multiwoz --sessions 30

# 需要手动：在 ABCD 数据上运行评测，对比分数分布
```

## 预期结果
- LLM 提取器泛化能力强（prompt 中已包含领域无关的通用指令）
- 模板提取器泛化能力弱（依赖领域特定规则）
- 目标域评测分数可能偏高或偏低（取决于域相似度）
