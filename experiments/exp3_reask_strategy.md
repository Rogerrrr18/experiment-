# 实验三：追问策略消融

## 目标
研究追问次数 N 对评测公平性和对话效率的影响。

## 假设
- H1: N=1 过于严格，Agent 一次未覆盖就被判失败
- H2: N=3 是 sweet spot，兼顾公平性和效率
- H3: N=∞ 会导致无限递归对话

## 变量
| 变量 | 取值 | 说明 |
|------|------|------|
| 最大追问次数 N | `1`, `3`, `5`, `10` | 核心自变量 |
| Agent 行为 | `helpful`, `partial`, `evasive` | 控制变量 |

## 指标
| 指标 | 说明 |
|------|------|
| 意图达成率 | N 增大时是否提升 |
| 平均对话轮次 | N 增大时是否膨胀 |
| 追问效率 | 追问有效利用的比例 |
| 递归检测触发次数 | N=∞ 时无限循环的概率 |

## 执行步骤

```bash
python src/run_experiment.py --exp exp3 --dataset multiwoz --sessions 20
```

## 预期结果
- N=1: 达成率最低（~60%），轮次最少（~8）
- N=3: 达成率适中（~85%），轮次合理（~12）
- N=5: 达成率高（~92%），轮次膨胀（~18）
- N=10: 达成率边际递减，接近 N=5，但轮次更长

**建议：N=3 作为默认值**
