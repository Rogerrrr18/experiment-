# 实验四：评分权重敏感性分析

## 目标
研究四项评分维度的权重配置对总分的影响，验证默认权重 (0.5/0.2/0.2/0.1) 的合理性。

## 权重配置

| 配置名 | 意图达成 | 追问效率 | 偏离率 | 轮次效率 | 设计意图 |
|--------|----------|----------|--------|----------|----------|
| **default** | 0.5 | 0.2 | 0.2 | 0.1 | 方法二论文默认 |
| equal | 0.25 | 0.25 | 0.25 | 0.25 | 等权重基准 |
| intent_heavy | 0.7 | 0.1 | 0.15 | 0.05 | 意图达成优先 |
| efficiency_heavy | 0.3 | 0.3 | 0.3 | 0.1 | 效率优先 |

## 指标
| 指标 | 说明 |
|------|------|
| 总分分布 | 不同权重下的分数分布差异 |
| 排序一致性 | 同一批 Agent 在不同权重下的排名 Kendall τ |
| 区分度 | 好 Agent 和差 Agent 的分数差距 |

## 执行步骤

```bash
python src/run_experiment.py --exp exp4 --dataset multiwoz --sessions 20
```

## 预期结果
- 四种配置对同一 session 的分数绝对值不同，但排序一致（Kendall τ > 0.8）
- default 配置在区分度和稳定性之间平衡最好
- intent_heavy 可能拉大 helpful vs evasive Agent 的差距（区分度更高）
